# 牙材庫存登記

Google Sheet 當資料庫，助理用手機網頁登記進貨／領用／報廢／盤點。

- 試算表：https://docs.google.com/spreadsheets/d/1mW59hFoXuxMimGD1b5nxX8QhJvhDVXVZHuJB69z-Vzs/edit

## 分頁

| 分頁 | 用途 | 誰動它 |
|---|---|---|
| 今日警示 | 該叫貨的材料、90 天內到期的批號 | 自動 |
| 材料主檔 | 材料清單、安全庫存；H–J 欄自動算目前庫存／最近效期／狀態 | 管理者新增材料 |
| 異動紀錄 | 每一筆進出（唯一的資料來源） | 手機表單寫入 |
| 批號效期 | 每個批號剩多少、幾天後到期 | 自動 |
| 設定 | 異動類型、材料分類、經手人名單 | 管理者 |

庫存 = 進貨 + 盤點調整 − 領用 − 報廢。不要直接改庫存數字，有落差就登記一筆「盤點調整」。

## 架設手機表單（約 5 分鐘）

1. 開試算表 → 擴充功能 → Apps Script
2. 把預設的 `程式碼.gs` 內容換成 `Code.gs`
3. 左側「＋」→ HTML → 命名 `Index`，貼上 `Index.html`
4. 右上「部署」→ 新增部署作業 → 類型選「網頁應用程式」
   - 執行身分：**我**
   - 存取權：**組織內的所有人**（Google Workspace）或「任何擁有 Google 帳戶的使用者」
5. 第一次會要求授權 → 允許
6. 複製網址 → 傳到診所 LINE 群組，讓助理加到手機主畫面

之後要改程式，就到「管理部署作業」→ 編輯 → 選「新版本」，網址不變。
